Simple Python Calculator

This is a simple calculator I made while learning Python.

It takes two numbers and an operator from the user and shows the result.

Operations

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

How to Run

Make sure Python is installed.

Run the following command:

python calculator.py

Example

First Number: 10
Operator (+, -, *, /): +
Second Number: 5
Result: 15.0
